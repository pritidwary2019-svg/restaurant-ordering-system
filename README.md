# 🍽️ Restaurant Ordering System

## 📌 About the Project

The Restaurant Ordering System is a beginner-friendly Python project that allows customers to view a restaurant menu, place multiple orders, select item quantities, and calculate their total bill.

This project was developed to practice Python programming fundamentals through a real-world application.

## ✨ Features

- Displays restaurant menu with item prices.
- Allows customers to order multiple food items.
- Supports quantity selection.
- Automatically calculates the total bill.
- Displays a final order summary.
- Provides a user-friendly command-line interface.

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Lists
- Loops
- Conditional Statements
- User Input and Output

## 🚀 How to Run the Project

**Step 1:** Clone this repository:

```bash
git clone https://github.com/pritidwary2019-svg/restaurant-ordering-system.git
```

**Step 2:** Open the project folder.

**Step 3:** Run the Python file:

```bash
python restaurant.py
```
